# Interactive Registration Form

## Project Overview

This project is an interactive conference registration form built with JavaScript to create a dynamic, user-friendly experience.

The form responds to user input by updating available options, calculating registration costs in real time, and displaying relevant payment fields based on the selected payment method.

It also incorporates custom form validation and accessibility features to provide immediate feedback, prevent invalid submissions, and improve the overall user experience.

## Technologies Used

- **HTML5** – Form structure and input elements
- **CSS3** – Form styling and visual feedback
- **JavaScript (ES6+)** – DOM manipulation, event handling, and dynamic form behavior
- **Regular Expressions (RegEx)** – Custom input validation

## What I Learned

This project strengthened my understanding of creating interactive forms and implementing client-side validation using JavaScript. I gained hands-on experience with:

- Dynamically updating form fields based on user selections
- Using event listeners to respond to user interactions
- Calculating and displaying activity registration costs
- Preventing users from selecting conflicting activities
- Implementing conditional logic to display payment information
- Writing custom validation functions using regular expressions
- Providing real-time visual feedback for valid and invalid inputs
- Improving form accessibility through clear error messaging and focus management
